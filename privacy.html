연습 초안 — 법률 검토 전 하루상점 개인정보 처리방침 1. 처리 목적 하루상점은 회원 로그인, 주문 처리와 배송, 결제, 주문 안내 메일과 배송 알림 발송, 이용 측정과 화면 개선, 광고 성과 측정을 위해 개인정보를 처리합니다. 2. 처리하는 개인정보 항목 - 회원: 이메일, 이름, 회원 식별 번호(UID), 로그인 방법(이메일/비밀번호 또는 Google) - 배송: 배송지 주소, 주소 이름표 - 주문: 산 상품, 금액, 주문 시각, 주문 상태 - 결제: 결제 정보(포트원이 처리) - 알림: 알림을 받는 기기 주소(토큰) - 자동으로 수집: 방문 · 클릭 기록(쿠키), 화면 기록과 클릭 위치, 구매 전환과 해시로 바꾼 이메일 3. 처리 및 보유 기간 - 회원 정보: 탈퇴할 때까지 - 알림 받는 주소: 알림을 끄거나 탈퇴할 때까지 - 주문 기록 · 결제 기록: 법이 정한 기간 - 확인 필요 - 자동으로 수집한 기록: 각 도구의 보관 설정을 따른다 - 확인 필요 4. 제3자 제공 확인 필요 5. 처리 위탁 - Google (Firebase): 회원 · 주문 · 알림 주소 보관 - 포트원: 결제 - Google (Gmail): 주문 확인 메일 발송 - Google (GA4 · Google Ads): 이용 · 광고 측정 - Microsoft (Clarity): 화면 기록 6. 파기 절차와 방법 - 회원이 탈퇴하면 회원 정보와 알림 받는 주소를 지웁니다. - 주문 기록은 법이 정한 기간 동안 남기고, 기간이 지나면 지웁니다. 남기는 근거: 전자상거래법 - 확인 필요. 남기는 항목: 주문 내역. - 결제 기록은 포트원의 보관 기간을 따릅니다 - 확인 필요. 7. 정보주체의 권리와 행사 방법 확인 필요 8. 개인정보 보호책임자 확인 필요 9. 자동으로 수집하는 장치의 설치 · 운영과 거부 방법 하루상점은 GA4, Microsoft Clarity, Google Ads를 사용하며 방문 · 클릭 기록을 쿠키로 수집합니다. 처음 방문할 때 뜨는 동의 배너에서 거부할 수 있습니다. 10. 해당될 때만 적는 항목 (가명정보 · 민감정보 등) 해당 없음
